# Terminal-Music-Player

This is my Terminal Music Player (TMP) that you can use for basic everday tunes.

# How it works

1.Program looks at the Music folder and finds the music/sound file.

2.After that user chooses the sound on the interface.

3.Lastly MiniAudio.h enables the song to play.

# Controls

Space to pause

esc (escape to quit the song)

#note

This program uses MiniAudio.h ( https://github.com/mackron/miniaudio/blob/master/miniaudio.h ) to play the music.
